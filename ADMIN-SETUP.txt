HOW IT WORKS
- Menu prices and availability refresh every 15 seconds while the page is visible.
- The customer can browse menu photos while connecting, but ordering is blocked if the database is unavailable.
- Prices & stock: edit the price, tick/untick Available, and Save for that item.
- Orders: shows latest 200 shared orders; refreshes every 15 seconds. Status and WhatsApp update are separate actions.
- New orders are saved BEFORE WhatsApp opens. Default status is Awaiting WhatsApp confirmation.
  Check that the customer sent their message before preparing. A redirect does not prove a message was sent.
- UPI screenshots remain in WhatsApp. Payments must be verified manually. Delivery charges remain separate.
- Order number is allocated in the database: HMTB-YYYYMMDD-001, -002, etc., based on India time.
- Customers do not need an account. The database recalculates totals and rejects unavailable items and invalid extras.
- The browser saves admin session tokens only in this tab's session storage. Use Sign out on shared devices.
- No secret/service-role key is included. Database permission policies protect private customer orders.
- The current admin can change existing prices and availability. Adding products, photos or reordering still requires a code update.
